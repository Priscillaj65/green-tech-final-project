# GreenTech Solutions Website

## Project Description
GreenTech Solutions is a multi-page responsive website designed to promote sustainability through technology. The site showcases eco-friendly services, educational resources, and information about green innovations that help reduce environmental impact.

---

## Features
- Home page with company mission and overview
- About page with company story and milestones
- Services page with searchable eco-friendly products/services
- Blog/Resources page with articles and sustainability tips
- Contact page with form and contact details
- Fully responsive design for mobile, tablet, and desktop
- Interactive search feature (JavaScript)
- Clean eco-friendly UI design
